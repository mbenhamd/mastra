## 2. Core concepts

This section defines the stable vocabulary used by the rest of the Harness v1
spec: harness/session boundaries, thread/resource identity, subagent ownership,
mode/model/skill concepts, local-vs-remote surfaces, workspace ownership, and
the small set of interchangeable terminology pairs the spec uses (§2.8).

**Entity ownership:** Harness, Session, Thread, Memory, Resource, Workspace —
see [§0 Mental model](../00-mental-model.md) for the canonical building/room/
notebook/logbook split before reading the child pages below.
