# Memory.deleteResource()

The `.deleteResource()` method deletes a resource record and its resource-scoped working memory. It doesn't delete threads or messages associated with the resource.

## Usage example

```typescript
const memory = await agent.getMemory()

await memory?.deleteResource('resource-123')
```

Calling the method for a resource that doesn't exist resolves successfully.
