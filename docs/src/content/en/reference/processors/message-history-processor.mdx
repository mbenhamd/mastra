# MessageHistory

The `MessageHistory` is a **hybrid processor** that handles both retrieval and persistence of message history. On input, it fetches historical messages from storage and prepends them to the conversation. On output, it persists new messages to storage.

## Usage example

```typescript
import { MessageHistory } from '@mastra/core/processors'

const processor = new MessageHistory({
  storage: memoryStorage,
  lastMessages: 50,
  persistence: {
    mode: 'final-turn',
    preserveModelOutputFor: ['publicSearch'],
    maxModelOutputBytes: 4096,
  },
})
```

## Extended usage example

```typescript title="src/mastra/agents/memory-agent.ts"
import { Agent } from '@mastra/core/agent'
import { MessageHistory } from '@mastra/core/processors'
import { PostgresStorage } from '@mastra/pg'

const storage = new PostgresStorage({
  connectionString: process.env.DATABASE_URL,
})

export const agent = new Agent({
  id: 'memory-agent',
  name: 'memory-agent',
  instructions: 'You are a helpful assistant with conversation memory',
  model: '__GATEWAY_OPENAI_MODEL__',
  inputProcessors: [
    new MessageHistory({
      storage,
      lastMessages: 100,
    }),
  ],
  outputProcessors: [
    new MessageHistory({
      storage,
      toolCallFilter: {
        preserveModelOutput: true,
        maxModelOutputBytes: 4096,
      },
    }),
  ],
})
```

## Behavior

### Input processing

1. Retrieves `threadId` from the request context
1. Fetches historical messages from storage (ordered by creation date, descending)
1. Filters out system messages (they shouldn't be stored in the database)
1. Merges historical messages with incoming messages, avoiding duplicates by ID
1. Adds historical messages with `source: 'memory'` tag

### Output processing

1. Retrieves `threadId` from the request context
1. Skips persistence if `readOnly` is set in memory config
1. Filters out incomplete tool calls from messages
1. Applies `toolCallFilter` when configured, removing matching raw tool arguments and results
1. Persists new user input and assistant response messages to storage
1. Updates the thread's `updatedAt` timestamp

## Filter persisted tool calls

Set `toolCallFilter` to remove tool calls and results at the persistence boundary. Omitting `exclude` removes all tool calls. Set `exclude` to filter selected tools only.

`preserveModelOutput` keeps compact model-facing output from completed results. It doesn't preserve media, incomplete states, denied results, failed results, raw arguments, or raw results. When `maxModelOutputBytes` is omitted, MessageHistory retains at most 16 KiB per preserved model output.

Set `preserveModelOutputFor` to retain compact output only for specified tools. An explicit empty list preserves no output. If the option is omitted, the existing `preserveModelOutput` behavior is unchanged.

When this persistence policy removes or compacts a tool payload, it also removes message-level provider metadata from that changed message. Messages without a matching tool payload remain unchanged by the tool-call policy.

```typescript
const messageHistory = new MessageHistory({
  storage,
  toolCallFilter: {
    exclude: ['searchDatabase'],
    preserveModelOutput: true,
    maxModelOutputBytes: 4096,
  },
})
```

## Persist only the final turn

Set `persistence.mode` to `final-turn` to store one stable user message, approved compact outcomes, and the final assistant text. This mode removes raw tool calls and results, reasoning, step markers, provisional text, transient assistant rows, and provider metadata.

`persistence` and `toolCallFilter` are mutually exclusive. Passing both throws a `TypeError` when `MessageHistory` is constructed.

Compact output is fail closed. Omit `preserveModelOutputFor`, or pass an empty list, to retain no tool output.

```typescript
const messageHistory = new MessageHistory({
  storage,
  persistence: {
    mode: 'final-turn',
    preserveModelOutputFor: ['publicSearch'],
    maxModelOutputBytes: 4096,
  },
})
```
